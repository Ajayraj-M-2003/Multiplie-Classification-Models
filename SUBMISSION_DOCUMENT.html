3. Assignment Details & GitHub README Content

a. Problem Statement

Credit card default prediction is a fundamental risk-management challenge for modern banking and credit institutions. Cardholders failing to meet debt obligations result in direct non-performing assets (NPAs) and heavy collections overhead. Conversely, misclassifying creditworthy clients impairs customer loyalty and forfeits interest revenue.

This assignment formulates credit default as a supervised binary classification task ($y \in \{0, 1\}$) to predict whether a customer will default on their credit card bill in the subsequent month. Five distinct classifiers—Logistic Regression, Decision Tree Classifier, K-Nearest Neighbors, Naive Bayes (Gaussian), and Support Vector Machine (RBF)—are trained, tuned, and evaluated on the same benchmark dataset across six mandatory performance metrics: Accuracy, ROC-AUC, Precision, Recall, F1-Score, and Matthews Correlation Coefficient (MCC).

b. Dataset Description

  • Dataset Name: Default of Credit Card Clients Dataset
  • Source: UCI Machine Learning Repository / Kaggle (UCI Link)
  • Target Variable: default (0 = No Default, 1 = Default Next Month)
  • Instance Count: 30,000 instances (exceeds assignment requirement of ≥ 500 instances)
  • Feature Dimensionality: 23 input features (exceeds assignment requirement of ≥ 12 features)
  • Class Balance: 23,364 non-default instances (77.88%) vs. 6,636 default instances (22.12%)
  • Features Breakdown:
    • Demographic (5): LIMIT_BAL (credit limit), SEX, EDUCATION, MARRIAGE, AGE.
    • Past Repayment Status (6): PAY_0 to PAY_6 (monthly repayment status from Apr–Sep 2005).
    • Bill Statement Amounts (6): BILL_AMT1 to BILL_AMT6 (monthly bill statements).
    • Previous Payment Amounts (6): PAY_AMT1 to PAY_AMT6 (monthly amounts paid).

d. Observations on Model Performance

ML Model Name Observation about model performance
Logistic Regression Achieves strong baseline accuracy (80.77%) and the highest precision (0.6868), minimizing false default alarms. However, recall is low (23.96%) because a linear hyperplane struggles to capture subtle delinquency interactions in an imbalanced target setting without heavy threshold tuning.
Decision Tree Highest performer overall with top ROC-AUC (0.7462), F1-Score (0.4657), MCC (0.3909), and Accuracy (81.72%). By recursively splitting on repayment delay flags (notably PAY_0 and PAY_2), it captures sharp non-linear risk thresholds while remaining well-regularized (max_depth=6).
KNN Delivers 79.80% accuracy and 0.7085 AUC. Distance-weighted neighborhood voting ($k=7$) clusters local borrower similarities, but suffers slightly from the curse of dimensionality across 23 features, leading to moderate precision (0.5697).
Naive Bayes Highest recall (55.39%) among all 5 models, detecting over half of true defaulters. However, the Gaussian independence assumption is violated by high multi-collinearity across consecutive monthly bill amounts (BILL_AMT1–BILL_AMT6), resulting in the lowest precision (45.15%).
Support Vector Machine Consistent high performance with 81.60% accuracy, 0.7210 AUC, and strong precision (0.6652). The RBF kernel maps features into a high-dimensional reproducing kernel Hilbert space to build a smooth non-linear decision surface.

🏆 Overall Winner for your dataset: Decision Tree Classifier

The Decision Tree Classifier is the clear overall winner. It achieved the highest ROC-AUC (0.7462), F1-Score (0.4657), and Matthews Correlation Coefficient (0.3909). Under financial credit risk with class imbalance (~22% defaults), MCC and F1 provide the true indicator of diagnostic power. Furthermore, Decision Tree provides sub-millisecond cloud inference and white-box rule interpretability vital for banking regulatory compliance.
